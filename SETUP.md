# Update your GitHub profile

1. Open https://github.com/rbhdsks/rbhdsks.
2. Save a copy of your existing README if you want a backup.
3. Replace the repository-root README.md with the included README.md.
4. Upload the assets folder so the banner is at assets/header.svg.
5. Commit the two files to the default branch. Visit https://github.com/rbhdsks to see the profile.

Upload the extracted files, not the ZIP itself. SETUP.md does not need to be uploaded.

The README uses GitHub-compatible Markdown, HTML links, and expandable details. The banner is a local SVG with no external font or image dependency. Interactive experiments open the existing Context Lab website; they do not execute within GitHub. No workflow, token, API key, or third-party statistics service is needed.
